# ADRとAgent Skills判断ガイドライン

## 概要

ADR（Architectural Decision Record）とAgent Skillsの使い分け判断基準。

---

## 🔴 CRITICAL: 30秒判断フロー

| 質問 | YES | NO |
|------|-----|-----|
| **1. 歴史的記録が必要か？**（なぜこの決定をしたか） | → **ADR** | → 次へ |
| **2. Claudeが自律的に適用すべきか？** | → 次へ | → 組織管理Doc/メモリー |
| **3. パターン・チェックリストとして表現可能か？** | → **Skills** | → ADR（実装ガイド含む） |

---

## ADR vs Skills 定義比較

| 項目 | ADR | Agent Skills |
|-----|-----|--------------|
| **目的** | 「**なぜ**」を記録 | 「**どう**」をガイド |
| **性質** | 歴史的文書・技術選定根拠 | 実行可能な知見・自律適用 |
| **内容** | Context/Decision/Consequences | パターン・チェックリスト |
| **参照タイミング** | 技術選定振り返り・オンボーディング | 実装時にClaude自律判断 |
| **形式** | `Doc/07_Decisions/ADR_XXX_*.md` | `.claude/skills/*/SKILL.md` |

**本質**:
- **ADR**: 「過去の意思決定」を後世に伝える
- **Skills**: 「Claudeが自律適用できるパターン」

---

## 判断基準マトリックス（5W1H）

| 観点 | ADR | Agent Skills |
|-----|-----|--------------|
| **What** | 技術決定・アーキテクチャ選択 | 実装パターン・判断基準 |
| **Why** | 意思決定の根拠記録 | 品質向上・自動適用 |
| **When** | 技術選定時・アーキ変更時 | コード実装時・品質チェック時 |
| **Who** | 人間（プロジェクトメンバー） | Claude Code（自律判断） |
| **Where** | `Doc/07_Decisions/` | `.claude/skills/` |

---

## 迷った時のチェックリスト

### ADRチェック（3問以上YES → ADR推奨）

- [ ] 1年後に「なぜこの決定をしたか」を知る必要がある
- [ ] 複数の選択肢から選んだ（代替案比較が必要）
- [ ] プロジェクト全体のアーキテクチャに影響
- [ ] リスク・トレードオフを含む
- [ ] 新メンバーのオンボーディング時に説明が必要

### Skillsチェック（3問以上YES → Skills推奨）

- [ ] 繰り返し使う実装パターン
- [ ] 自動チェック・自動適用可能
- [ ] Claudeが状況に応じて自律判断すべき
- [ ] コード品質向上に直結
- [ ] パターン・チェックリストとして表現可能

## 判断例

### ADR適合例

| ADR | 理由 |
|-----|------|
| **ADR_016（プロセス遵守）** | 過去の失敗から学んだ教訓→歴史的記録 |
| **ADR_020（テストアーキテクチャ）** | アーキテクチャ選択の根拠→将来の変更時参照 |
| **ADR_005（PostgreSQL採用）** | 技術スタック選定→意思決定の根拠 |

### Skills適合例

| Skill | 理由 |
|-------|------|
| **fsharp-csharp-bridge** | F#↔C#型変換パターン→繰り返し使う実装パターン |
| **clean-architecture-guardian** | レイヤー分離チェック→自動監視可能 |
| **playwright-e2e-patterns** | E2Eテスト実装パターン→自律適用可能 |

---

## ハイブリッドアプローチ

両方に該当する場合、ADR（決定根拠）+ Skills（実装パターン）の併用。

**例**:
- **ADR_020**: なぜレイヤー×テストタイプ分離にしたか
- **test-architecture Skill**: 命名規則・参照関係の自動チェック

---

## どちらにも該当しない場合

| 選択肢 | 配置 |
|--------|------|
| 組織管理ドキュメント | `.claude/rules/operations/` or `Doc/08_Organization/Guide/` |
| Serenaメモリー | セッション開始時参照情報 |
| 一時的メモ | `Doc/04_Daily/` セッション記録 |
