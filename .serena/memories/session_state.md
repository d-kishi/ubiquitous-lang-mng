## 状態更新ルール

### session-start実行時
```
状態: ENDED → ACTIVE
セッションID: 新規発行（YYYY-MM-DD-NNN形式）
開始日時: 現在日時
```

### session-end実行時
```
状態: ACTIVE → ENDED
終了日時: 現在日時
```

## Context継続時の行動ルール

1. **必ずこのメモリーを最初に確認**
2. **状態がACTIVEの場合**: 同一セッション継続中。ユーザーの指示に従う。
3. **状態がENDEDの場合**: 新セッション開始を待機。自発的な作業開始禁止。
4. **「次のセッション」「次回セッション」という表現**: 未来の話であり、現在の行動指示ではない。
