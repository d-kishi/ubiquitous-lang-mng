# Doc/08_Organization/Guide/

## 概要

プロジェクト運用に関する詳細ガイド・テンプレート・戦略ドキュメントを配置するディレクトリ。

**作成日**: 2025-12-17
**Issue**: #83 ルール管理基盤改善

## 配置基準

以下の特性を持つドキュメントを配置：

- **ガイド**: 実装・運用の詳細手順書
- **テンプレート**: Phase・Step計画の参考テンプレート
- **戦略**: 技術戦略・統合方針ドキュメント
- **マスタープラン**: 大規模実装の全体計画

## 配置ファイル一覧

| ファイル | 内容 |
|----------|------|
| テスト戦略ガイド.md | TDD・テストファースト開発の詳細戦略 |
| Phase特性別テンプレート.md | Phase規模別の計画テンプレート |
| 新規テストプロジェクト作成ガイドライン.md | テストプロジェクト作成の詳細手順 |
| MCP設定メンテナンスガイド.md | MCP環境のメンテナンス手順 |
| Playwright_運用統合ガイドライン.md | Playwright MCP・Agents運用統合 |
| 縦方向スライス実装マスタープラン.md | 縦方向スライス実装の全体計画 |

## ルールとの関係

- **厳格なルール**: `.claude/rules/`に配置（自動読み込み対象）
- **詳細ガイド**: 本ディレクトリに配置（参照時のみ読み込み）

ルールファイルから本ディレクトリのガイドを参照する場合：
- `.claude/rules/tests/new-test-project-checklist.md` → `新規テストプロジェクト作成ガイドライン.md`

## 関連ディレクトリ

- `.claude/rules/` - 厳格なルール（自動適用）
- `Doc/08_Organization/Rules/backup/` - 廃止・移行済みルール
- `Doc/08_Organization/Completed/` - 完了Phase記録
